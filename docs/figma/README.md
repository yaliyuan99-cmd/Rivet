# The Figma source

File: `Untitled` in the Rivet team folder, https://www.figma.com/design/NiSg6a7Cm51Q7DriS7JNda/Untitled

One page with 151 top-level frames: 37 screens, each in Desktop and Mobile, Light and Dark, plus a UI kit in each theme and a token sheet. The file has no prototype links ("Static states only"), so the site's navigation comes from the frame names.

- `frames/` holds exact text dumps: every Desktop/Light screen, three mobile screens, the light UI kit, tokens and styles. The format is explained in `docs/BUILDING.md`.
- `shots/` holds reference images of a sample of frames.

The screens, in order: Access (signup, verify, home); Evaluation (editor, freeze, running, interrupted, results, evidence); Expert review (apply, pending, credentials, expert, adjudication); Published evidence (leaderboard, report, copied); Workspace (create, members, private); Datasets (upload, list, detail, delete); Agent assurance (trace, regression, blocked, passed); External access (consent, approved, denied, expired); Discovery and profile (browse, profile); Audit Advisor; Administration (models, checks).
